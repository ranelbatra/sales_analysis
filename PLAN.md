# Overview

Sales Analysis of Iowa Liquor Sales, Target

# Problem Statement

Large retail transaction datasets contain valuable information that can help businesses understand purchasing patterns, product performance, and revenue trends. However, the raw Iowa Liquor Sales dataset is complex and difficult to interpret directly due to its large size and numerous attributes. There is a need to analyze and visualize the data to identify sales trends, high-performing products, revenue-generating locations, and the factors influencing liquor sales.

# Goals

1. Perform exploratory data analysis to understand the structure and characteristics of the dataset.
2. Analyze sales trends over time and identify seasonal purchasing patterns.
3. Evaluate product and brand performance based on sales and purchase quantities.
4. Assess vendor contributions and determine major suppliers.
5. Examine the relationship between pricing, bottle size, and sales performance.
6. Generate meaningful visualizations and insights that support data-driven decision-making.

# Non-Goals

1. Developing predictive machine learning models for forecasting sales.
2. Building a recommendation system for liquor products.
3. Performing real-time data processing or streaming analytics.
4. Creating customer-level profiling or personalization systems.
5. Modifying or collecting additional data beyond the provided dataset.

# User Stories (Priority Wise)

1. As a data analyst intern, I want to clean and preprocess the Iowa Liquor Sales dataset so that I can prepare it for analysis.
2. As a data analyst intern, I want to perform exploratory data analysis so that I can understand the structure and characteristics of the dataset.
3. As a data analyst intern, I want to analyze monthly and yearly liquor sales trends so that I can identify seasonal patterns in sales.
4. As a data analyst intern, I want to identify the top-performing liquor categories and stores so that I can determine the major contributors to revenue.
5. As a data analyst intern, I want to analyze vendor and brand performance so that I can identify the major suppliers and most popular products.
6. As a data analyst intern, I want to determine which counties and cities generate the highest revenue so that I can understand geographical sales patterns.
7. As a data analyst intern, I want to calculate descriptive statistics and correlations among numeric features so that I can uncover relationships within the dataset.
8. As a data analyst intern, I want to examine the relationship between bottle size and sales so that I can understand factors influencing purchase quantities.
9. As a data analyst intern, I want to analyze the distribution of bottles sold per transaction and bottle sale prices so that I can understand purchasing and pricing behavior.
10. As a data analyst intern, I want to create visualizations and dashboards so that I can effectively communicate insights and findings.

# Requirements

## Functional Requirements

1. Load and preprocess the Iowa Liquor Sales dataset.
2. Perform exploratory data analysis on all relevant attributes.
3. Generate visualizations including bar charts, line charts, scatter plots, heatmaps, histograms, and box plots.
4. Calculate descriptive statistics and correlations among numeric features.
5. Analyze sales by category, brand, store, vendor, county, and city.
6. Produce reports and dashboards summarizing key findings.

## Non-Functional Requirements

1. The system should efficiently process large datasets containing over 200,000 records.
2. The analysis pipeline should be modular, reusable, and easy to maintain.
3. Visualizations should be clear, interactive, and easy to interpret.
4. The solution should ensure data consistency and reproducibility of results.
5. The analysis should be scalable to accommodate future dataset updates.

# Success Metrics

1. Successful processing and analysis of all 224,201 transaction records without data loss.
2. Generation of accurate visualizations for all identified business questions.
3. Identification of top-performing categories, stores, vendors, and regions based on sales metrics.
4. Detection of meaningful seasonal trends and correlations within the dataset.
5. Delivery of actionable insights that can support business and inventory decision-making.
